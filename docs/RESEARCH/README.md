# Research inbox

**Put research, references, competitor notes and ideas here — not in chat.**

A conversation is not a memory. When a session grows long it is compacted, and
anything that lived only in the chat is gone: earlier research sent this way was
lost exactly that way, and could not be mined for ideas because it no longer
existed to read.

A file in this repository survives compaction, survives new sessions, and
survives a different person picking up the work. It can be read, cited, and
turned into tasks.

## How to add

Drop a file in this folder. Any format: `.md`, `.txt`, a pasted export, a link
list. Naming does not matter. Rough notes are fine — unstructured is fine.

## What happens to it

Each item is read, and turned into one of:

- a task in `docs/ROADMAP.md`, if it is buildable
- a source in `docs/SOURCES.md`, if it is a data source
- a ring entry in `docs/TECH_RADAR.md`, if it is a technology decision
- a documented **rejection with a reason**, if we should not do it — so it is
  not raised and re-litigated later

Nothing is silently dropped, and nothing is silently accepted.
