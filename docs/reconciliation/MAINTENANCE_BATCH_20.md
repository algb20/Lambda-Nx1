## W4 — Quarantine recheck, and a defect it exposed

A live run of `recheckQuarantine` checked all 50 entries:
- 48 still refused, empty or stale;
- one, `eluniversal_mx`, was reported **recovered** (100 items, newest the same day), and the run advised releasing it.

**The advice was wrong.** The source is quarantined because:
- its `robots.txt` (edition of 24 Sep 2026, re-read today) still disallows every agent not on its list;
- the registry records it PROHIBITED.

A reachable feed is not a permitted one.

| | |
|---|---|
| **Root cause** | `judgeProbe` judges the network answer only, and nothing checked the licence before advising a release. |
| **Patch** | New `licenceHold(source)`, which returns the catalogue `licenceProblem` or a registry WITHHOLD status. A "recovered" verdict for a held source becomes **`answers-but-withheld`**, with the reason in the detail, and it never appears in the release advice. |
| **Tests** | `recheck.test.ts`: every held source that answers is held, never recovered. `eluniversal_mx` is the observed case. An allowed source has no hold. |

## W3 — Field research, and the AI-text disclosure it required

The research is in `docs/RESEARCH/FIELD_2026-10-08.md`; every platform finding is DISCOVERED. One finding is a legal duty already in force.

**EU AI Act**, read on the Commission's AI Act Service Desk (EUR-Lex returned an empty 202 to this network, which was not worked around):
- **Art. 50(4):** text generated by AI and "published with the purpose of informing the public on matters of public interest" must be disclosed as artificially generated.
- **Art. 50(5):** the disclosure must be "clear and distinguishable".
- **Art. 113:** Article 50 applies from 2 August 2026.
